# Bill of Materials

Parts list for Project MJOLNIR.

## Armor

| Item | Description |
|---|---|
| PLA filament (Bambu Lab) | Printed armor shell and some accessories |
| EVA foam | Interior padding for each armor piece |
| Fiberglass cloth | Interior reinforcement |
| Fiberglass resin | Bonds the cloth and stiffens the shell |
| Barge All-Purpose Cement | Attaches foam to the armor interior |
| Tactical gloves | Base for the HEPHAESTUS gauntlets ([link](https://a.co/d/02feybc5)) |

## Helmet

| Item | Description |
|---|---|
| XREAL Air AR glasses | HUD display |
| Floodlights | LED modules for the sides of the helmet ([link](https://www.amazon.com/Aluminum-Circuit-Module-300-330LM-Natural/dp/B08HRHZ9H2)) |
| Raspberry Pi Camera Module 3 NoIR | Night vision camera |

## Electronics

| Item | Description |
|---|---|
| Raspberry Pi 5 | Runs the HUD and wrist display |
| Arduino-compatible board | Reads the sensors, sends data to the Pi over USB serial |
| Waveshare 2" LCD module | Wrist vitals display, 240×320 IPS, SPI ([link](https://www.amazon.com/2inch-LCD-Module-Resolution-Communicating/dp/B081NBBRWS)) |

## Sensors

| Item | Description |
|---|---|
| MAX30102 | Pulse and blood oxygen (finger) |
| MAX30205 | Body temperature (finger) |
| MPU6050 | Accelerometer for gesture control |
| DHT11 | Suit temperature and humidity |
| HC-SR04 | Ultrasonic distance sensor for RearGuard |
